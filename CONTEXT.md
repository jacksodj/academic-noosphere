# Academic Noosphere

A Mac-local app for a single researcher that surveys an academic field and surfaces
grounded literature gaps. This glossary is the project's canonical language; planning
lives on the wayfinder map (issue #1).

## Language

**Survey**:
One run of the pipeline over a Field: discovery, resolution, graph update, and analysis,
producing a Gap Report and a Run Snapshot. Runs in two phases: a coarse pass over a
tight core corpus surfaces Whitespace Candidates; bounded zoom passes ingest deeper and
confirm or refute each at fine grain.
_Avoid_: crawl, scan, harvest

**Field**:
The scope of a Survey, named at OpenAlex-topic / arXiv-category granularity. The first
Field is the intersection *memory for AI agents* — agent memory architectures informed
by human memory science (episodic/semantic memory, consolidation, forgetting).
_Avoid_: domain, area, subject

**Gap Report**:
The app's headline output for a Survey: grounded literature gaps with evidence, plus an
optional Ideonomy Expansion section.
_Avoid_: analysis, summary

**Whitespace Candidate**:
A coarse-grained region of the Field flagged as potentially under-explored by Phase-1
analysis of a Survey's core corpus. Confirmed or refuted at fine grain by a zoom pass;
only confirmed candidates become gaps in the Gap Report.
_Avoid_: gap (until confirmed), opportunity

**Structural Gap**:
A sparse or empty region of a Field's idea-space, computed from the graph (topic
communities, coverage matrix). Always evidence-backed.

**Narrative Gap**:
A gap authors state in prose ("future work should examine X"), mined from Web Search
snippets and paper abstracts, cited to its sources.

**Ideonomy Expansion**:
The speculative section of a Gap Report: ideas generated by applying a randomized
ideonomic method tuple (operators × organon × dimension-prompts, per
latentwill/ideonomy-skill) to a selected gap. Always segregated, always labeled
speculative, each idea citing its nearest existing work.
_Avoid_: brainstorm, idea list

**Grounded Claim**:
A statement in any report carrying an inline citation that resolves to a DOI/OpenAlex ID,
or a URL plus retrieval date for Web Search findings. Any unlabeled statement that is not
a Grounded Claim is a bug.

**Run Snapshot**:
The full set of resolved DOI/OpenAlex IDs a Survey's analysis was computed over — the
reproducibility artifact every report is linted against. Lives beside the graph, not
in it: the graph records what the literature is; snapshots record what a Survey did.
_Avoid_: cache, export

**Discovery**:
Finding candidate work identifiers (titles/DOIs/URLs) via AgentCore Web Search. Discovery
output is never persisted as content; only identifiers move forward to Resolution.
_Avoid_: search results ingestion

**Resolution**:
Turning a discovered identifier into a canonical record via scholarly APIs (OpenAlex
primary). Only resolved records enter the graph.
_Avoid_: enrichment, lookup
